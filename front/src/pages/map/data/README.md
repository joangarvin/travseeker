# Country outlines

Natural Earth, Admin 0 countries, 1:50m, v5.1.2. Extracted ES/PT/FR/MA; all geometry retained, other attributes removed. Public domain. Accessed 2026-10-23.

These shapes are an overview aid, not legal boundaries. Only countries with published map results are drawn. New countries without bundled outlines still get their country label.
